## SHOHIN AI Image Generator

В HAWO добавлен отдельный раздел генерации изображений по текстовому описанию.

- Интерфейс: `image-generator.html`
- Backend-шаблон для Hugging Face Space: `ai-backend/`
- Модель по умолчанию: `black-forest-labs/FLUX.1-schnell`
- Токен модели хранится только в Secrets backend, не в браузере и не в GitHub.

### Подключение генерации

1. Создайте Hugging Face Space с SDK Docker.
2. Скопируйте содержимое папки `ai-backend/` в корень Space.
3. В Settings → Variables and secrets добавьте Secret `HF_TOKEN` с разрешением Inference Providers.
4. После запуска скопируйте адрес Space (например, `https://имя-пользователя-hawo-ai.hf.space`).
5. Откройте SHOHIN AI в HAWO и вставьте адрес backend в поле API.

Важно: сам интерфейс уже находится в HAWO, но генерация начнёт работать только после развёртывания backend и добавления действующего токена. Запросы к провайдеру могут быть платными или ограничиваться доступными кредитами.


## SHOHIN AI Assistant

Откройте `assistant.html` или нажмите SHOHIN AI ASSISTANT на главной странице HAWO.

Первая локальная версия включает:
- чат-помощник по функциям HAWO;
- подсказки по типовым проблемам погоды и GPS;
- тренировочные диалоги на таджикском, русском, английском и китайском;
- выбор разговорного сценария: повседневная речь, магазин, путешествие и работа;
- необязательный голосовой ввод, если браузер поддерживает Speech Recognition.

### Локальное интеллектуальное ядро

SHOHIN AI подключён к открытой модели `Qwen3-0.6B-ONNX` через Transformers.js.

- Модель выполняется в браузере на устройстве пользователя: WebGPU при наличии поддержки, иначе CPU/WASM.
- Квантованные веса загружаются из публичного репозитория Hugging Face при первом запуске и сохраняются в браузерном Cache API.
- После успешной первой загрузки модель может генерировать ответы без интернета, если браузер не удалил её кэш.
- Платные API, API-ключи и собственный сервер для текстового диалога не используются.
- Режимы: поддержка HAWO и разговорная практика с коррекцией ошибок.
- Языки интерфейса и общения: таджикский, русский, английский и китайский.

Первая загрузка требует интернет и примерно 570 МБ при WebGPU или до 920 МБ при CPU/WASM. Фактическое потребление памяти выше размера файла. На некоторых Android-браузерах WebGPU может быть недоступен; тогда используется более медленный CPU/WASM. Пользователь должен нажать «Загрузить SHOHIN AI» и дождаться завершения загрузки. Не очищайте данные сайта, если хотите сохранить модель для офлайн-работы.

Qwen3 заявляет поддержку 119 языков и диалектов, включая таджикский, русский и китайский. Качество на малой модели 0.6B ограничено: ответы могут быть неточными, особенно при сложной диагностике. SHOHIN AI не читает системные логи автоматически — для разбора ошибки пользователь должен вставить её текст.

Важно: этот режим предназначен для обычного диалога и помощи. Он не заменяет проверку критически важных технических, медицинских или юридических решений.


## SHOHIN AI — общий онлайн-движок

В папке `ai-core/` добавлена основа самостоятельного серверного ядра SHOHIN AI:

- один backend для разных приложений SHOHIN;
- отдельные профили `english`, `tajik-chinese`, `dictionary`, `weather` и `generic`;
- генерация на собственной машине через llama.cpp и GGUF-модель;
- API `POST /v1/chat` и проверка состояния `GET /health`;
- общий браузерный клиент `ai-core/client.js`.

Это серверная основа, а не уже опубликованный онлайн-сервис. Для реальной работы нужно развернуть backend на постоянно работающем сервере, положить туда GGUF-модель, настроить HTTPS и защиту от злоупотреблений, а затем подключить URL сервера в приложениях. Платные API сторонних ИИ не используются, но вычислительный сервер может требовать расходов. До публичного запуска необходимо добавить полноценную авторизацию и общий лимит запросов.


### Подключение HAWO к онлайн-ядру

1. Разверните backend из `ai-core/` на собственном сервере с GGUF-моделью и HTTPS.
2. Убедитесь, что адрес `https://ВАШ-ДОМЕН/health` возвращает JSON с `"ok": true`.
3. Откройте HAWO → SHOHIN AI ASSISTANT.
4. В блоке «Онлайн-ядро SHOHIN AI» вставьте корневой HTTPS-адрес сервера (без `/health` и без завершающего слеша).
5. Нажмите «Проверить сервер». После успешной проверки чат будет отправлять запросы в серверный профиль `weather`.
6. Если сервер не настроен или недоступен, можно использовать резервную локальную модель Qwen3 на устройстве.

В текущей версии HAWO уже загружает общий клиент `ai-core/client.js`, проверяет `/health` и отправляет историю чата на `/v1/chat`. Публичный URL backend пока не задан; поэтому онлайн-генерация ещё не может быть проверена в живом приложении.
