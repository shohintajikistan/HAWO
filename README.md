# SHOHIN WEATHER 🇹🇯

Погодное PWA-приложение для Таджикистана.

## Возможности

- 🌤 Текущая погода
- 🕐 Почасовой прогноз
- 📅 Прогноз на 7 дней
- 💧 Влажность
- 💨 Ветер
- 🌡 Давление
- 👁 Видимость
- 🌫 Качество воздуха
- 📍 GPS
- 🔍 Поиск города
- 📱 PWA
- 🇹🇯 Только Таджикистан

## Технологии

- HTML
- CSS
- JavaScript
- WeatherAPI
- Cloudflare Workers
- GitHub Pages
- PWA

## Архитектура

SHOHIN WEATHER
↓
Cloudflare Worker
↓
WeatherAPI

API-ключ WeatherAPI хранится только
в Cloudflare Worker и не публикуется
в GitHub или приложении.
